perf(frontend): extract formatter functions outside component

Summary: Moved `formatGear`, `formatPedal`, and `formatTime` outside of the `App` component in `frontend/src/App.tsx`.
Motivation: The formatter functions do not depend on component state or props and were unnecessarily re-created on every render, causing slight CPU and memory overhead.
Benchmarks & Metrics: Baseline performance using an isolated benchmark script:
- Inline functions: 1242.31 ms
- Extracted functions: 875.80 ms (29.5% faster execution time for 10,000,000 iterations).
Verification: Run `npm run lint` and `npm run build` in the frontend directory. No issues or warnings found. No functionality changed.
